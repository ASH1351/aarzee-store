# AARZEE STORE — Haute Parfumerie & Traditional Indian Attars

A production-quality, cinematic 3D e-commerce website crafted for **AARZEE STORE**, a luxury perfume and Indian attar house rooted in the ancient hydro-distillation traditions of Kannauj and Assam.

---

## ✨ Features

- **Official Brand Identity:** Accurate circular red monogram brand mark, deep obsidian black palette with champagne gold accents.
- **Cinematic 3D Perfume Engine:** Interactive Three.js / React Three Fiber flacon with physical obsidian glass transmission, ruby red liquid core, metallic cap, and fragrance mist particle physics.
- **"THE ESSENCE OF AARZEE" 3D Experience:** 360° interactive flacon orbit with olfactory pyramid callout annotations (Top, Heart, Base notes) and liquid hue selector.
- **Traditional Attar Atelier:** Celebrates the heritage of *Deg & Bhapka* copper alembic distillation and 100% non-alcoholic perfume oils.
- **Interactive Fragrance Notes Explorer:** Visual categorization of Citrus, Floral, Woody, and Oriental notes with scent mist simulations.
- **Complete E-Commerce Architecture:**
  - Slide-in Cart Drawer with dynamic free shipping progress meter.
  - VIP coupon redemption (`AARZEE10` for 10% off).
  - Direct simulated checkout modal with celebration confetti.
  - Curated Wishlist drawer with instant "Move to Bag".
  - Live search modal indexing names, accords, and notes.
- **Product Detail Dossiers:** Dynamic 3D / Still photo toggle, size selectors, quantity controls, and comprehensive accordion dossiers.
- **Custom Desktop Cursor:** Magnetic cursor with dynamic labels (`VIEW`, `EXPLORE`).
- **Complete Technical SEO:** Dynamic `sitemap.xml`, `robots.txt`, Open Graph / Twitter cards, and Schema.org structured data (`Organization`, `WebSite`, `Product`, `BreadcrumbList`, `FAQPage`).

## 🚀 Getting Started

### 1. Installation
```bash
git clone https://github.com/ASH1351/aarzee-store.git
cd aarzee-store
npm install
```

### 2. Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
